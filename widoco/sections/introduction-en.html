Introduction back to ToC

The Space Types Ontology (SPOT) describes spaces and how entity spaces appear in reference spaces. SPOT-SG connects this structure to the Geometry Metadata Ontology (GOM): every SPOT Space is treated as a coordinate system and every SPOT Appearance as a coordinate system transformation, so that SPOT instance data can be read as a scene graph. In addition, SPOT-SG introduces a compact bounding box literal for spaces.
